## 为甚么是 680 bytes

fx-50FH（及 fx-50FH II / fx-50F PLUS）是香港 DSE 常用型号，程式区 **680 bytes**，用 CASIO 自家的类 BASIC 语言。每个程式都要把键入空间、变数、统计模式算进这 680 bytes，所以原页每条都标了自身体积——这是硬预算，不是建议。这里最长的一条是 MindMaster 解答，494 bytes；最短的估数字 32 bytes。

## 收录了甚么

每个档案（`games/NN-slug.md`）都包含：

- **YAML front matter** — 原始标题、英文名、来源网址、程式数、标称位元组数、日期
- **署名 / Credits** — 原页的署名原文，一字不改
- **程式码区块** — 原样转录，未经改动
- **玩法与说明（原文）** — 原页的操作步骤
- `index.json` — 机器可读的总目录

## 快速键入

1. 选一个空程式位（`Prog` 键切换）
2. 需要时先设模式，部分程式要求 `REG Lin`（按 `5 1`）
3. 逐行键入程式码。`E` 是按 `EXP`；上标的 `M` 是按 `ALPHA M+`
4. 按 `Prog N` 执行，再照该页玩法操作

键入后 bytes 对不上，通常是漏了 `:`、或把负号 `-` 和减号 `−` 搞混。
