## 為甚麼是 680 bytes

fx-50FH（及 fx-50FH II / fx-50F PLUS）是香港 DSE 常用型號，程式區 **680 bytes**，用 CASIO 自家的類 BASIC 語言。每個程式都要把鍵入空間、變數、統計模式算進這 680 bytes，所以原頁每條都標了自身體積——這是硬預算，不是建議。這裡最長的一條是 MindMaster 解答，494 bytes；最短的估數字 32 bytes。

## 收錄了甚麼

每個檔案（`games/NN-slug.md`）都包含：

- **YAML front matter** — 原始標題、英文名、來源網址、程式數、標稱位元組數、日期
- **署名 / Credits** — 原頁的署名原文，一字不改
- **程式碼區塊** — 原樣轉錄，未經改動
- **玩法與說明（原文）** — 原頁的操作步驟
- `index.json` — 機器可讀的總目錄

## 快速鍵入

1. 選一個空程式位（`Prog` 鍵切換）
2. 需要時先設模式，部分程式要求 `REG Lin`（按 `5 1`）
3. 逐行鍵入程式碼。`E` 是按 `EXP`；上標的 `M` 是按 `ALPHA M+`
4. 按 `Prog N` 執行，再照該頁玩法操作

鍵入後 bytes 對不上，通常是漏了 `:`、或把負號 `-` 和減號 `−` 搞混。
