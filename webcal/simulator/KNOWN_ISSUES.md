# 待办：需要原页修正的数据问题

模拟器侧已完成的与无法完成的，这里列清楚。以下三项**根在源数据**，模拟器不修改源程序（遵守「不改动代码」的约定）。

## 1. 14、15 号对战游戏 —— 无法载入

原页 `fighting.htm`、`fighting2.htm` 的程序里有裸文本 `BAD`、`GD`：

```
D => BAD◢ Y=>GD◢ Norm 1
```

fx-50F PLUS 没有字符串显示功能，也没有 `G` 变量（变量只有 A–F、X、Y、M）。
`BAD` / `GD` 应该是某种被排版吃掉的内容，例如 `B A D` 的隐式乘法，或原本该是别的记号。

**需要确认**：这两处原本是什么？

## 2. 18 号记忆游戏 —— 运行时报 Syntax ERROR

`Rnd( A ÷ 10 - 0.5 :` 这行的括号没有闭合：

```
For 1→A To 7E3: Fix 0: Rnd(A％- . 5→Y: Rnd(A÷10-.5:
```

**需要确认**：`Rnd(` 的右括号在哪？

> 附注：真机上 `:` 会闭合括号，所以「无条件断句」才是正确语义。但一旦这么改，03–07 五条程序会因原页括号同样残缺而行为改变。目前模拟器选择「括号未闭合时不切句」，代价是 18 号无法运行，且 03–07 的执行路径与原机不完全等价。

## 3. 字节数标注口径不一致

各页标称的 bytes 数算法不统一：

- 13 号 `guess-position`：标称 60，按 token 数计正好 60，但按字符数计是 66
- 多数页面：按字符数（数字每位算 1 字节）

**需要确认**：标称值是按 token 数还是字符数计的？
