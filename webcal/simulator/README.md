# CASIO fx-50F PLUS / fx-50FH 网页模拟器

在浏览器里运行 CASIO fx-50F PLUS，可直接载入并执行 `../games/` 里的游戏程序。

## 打开方式

双击 `index.html` 即可。或起一个本地静态服务器：

```bash
cd webcal/simulator
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

需与 `../games/` 保持相对位置，**不要把 `simulator/` 单独拷走**。

## 四种模式

按 `MODE` 循环切换：**COMP → SD → REG → PRGM → COMP**

### COMP — 普通计算

按键输入算式，`EXE` 求值。支持隐式乘法（`6A` = 6×A）、括号、上标。

| 键 | 说明 |
|---|---|
| `x²` `x³` `x⁻¹` | 平方/立方/倒数 |
| `√` | 平方根（`SHIFT`+`√` = 立方根） |
| `log` `ln` | 常用对数/自然对数（`SHIFT`+`log` = 10^x，`SHIFT`+`ln` = e^x） |
| `sin` `cos` `tan` | 三角函数（`SHIFT` 为反函数） |
| `EXP` | ×10 的幂 |
| `Ans` | 上次结果 |
| `DEL` / `AC` | 退格 / 全清 |

### SD — 单变量统计

输入数值按 `EXE` 录入一个数据点，屏幕显示当前样本数 `n`。
`Ans` 键循环读取：`n` → `Σx` → `Σx²` → `x̄` → `Σy` → `Σxy`。

### REG — 回归（线性）

输入 `x,y` 按 `EXE` 录入数据对。切换进入统计模式时会清空统计内存——与真机一致。

### PRGM — 程序

- `÷` / `×` 切换程序，`EXE` 执行
- 直接按数字和功能键会**写入程序缓冲区**，屏幕第二行实时显示占用字节
- `DEL` 退格，`AC` 退出
- 执行中：`?` 提示输入数字，`EXE` 确认；`◢` 显示结果后按 `EXE` 继续

## 自订程序

页面下方输入框可粘贴任意程序，点「计算 bytes」看占用，点「执行」直接运行。

## 已知限制

原页面的数据本身存在问题，以下无法在模拟器侧修复：

- **14、15 号对战游戏**：原页含 `BAD`、`GD` 裸文本。fx-50F PLUS 无字符串显示、无 G 变量，判为数据损坏，不载入。
- **18 号记忆游戏**：原页括号残缺（`Rnd( A ÷ 10 - 0.5 :` 未闭合）。修复它需要把 `:` 无条件断句，但那会破坏 03–07 五条程序，故不做。
- **02 号猜数字**：可运行，但属盲猜游戏，随机输入命中率极低。
- **01 号程序**转录代码不输出 1/-1 提示（`=> Goto 0` 在 `◢` 之前跳转），与原页说明文字不符。

**字节计数**：按「每 token 1 字节 + 数字每位 1 字节」计算。16 条中 11 条与标称值一致；不一致处是原页对多位数的计法不统一（如 13 号按 token 数计）。程序列表中会同时显示「标称b(算Nb)」。
