# fx-50F PLUS / fx-50FH 网页模拟器

浏览器里运行的 CASIO fx-50F PLUS 模拟器，可直接载入并运行 `../games/` 里的游戏程序。

## 打开方式

双击 `index.html`，或在本目录起一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

需要从 `../games/` 目录载入程序，因此**不要单独拷走这个目录**，保持 `webcal/` 结构完整。

## 功能

| 功能 | 状态 |
|---|---|
| COMP 模式四则/函数计算 | ✅ 可用 |
| 隐式乘法（`6A`）、上标（`x²`/`x³`/`x⁻¹`） | ✅ |
| PRGM 模式：浏览 18 条程序并执行 | ✅ |
| `?` 输入提示、`◢` 停显、`M+`/`M-` | ✅ |
| 六十进数输出（度分秒） | ✅ |
| 自定义程序粘贴 + 字节数计算 | ✅ |
| SD/REG 统计模式（`DT`、`Σx`、回归） | ⚠️ 部分 |
| 14、15 号对战游戏 | ❌ 原始数据损坏，不载入 |
| 18 号记忆游戏 | ❌ 原页括号未闭合，语句切分失败 |

## 结构

- `engine.bundle.js` — 引擎（词法、解析、求值、程序执行），由 `core.js`/`engine.js`/`prog.js` 打包生成
- `programs.js` — 从 `../games/*.md` 提取的程序数据
- `ui.js` — 键盘、LCD、模式状态机

## 已知差异

- 14、15 号程序原页含 `BAD`/`GD` 裸文本，真机无字符串显示，判为数据损坏，未收录。
- 字节计数按「每 token 1 字节 + 数字每位 1 字节」估算，多数程序与标称值一致，个别有 ±几字节差异。
- 01 号程序的转录代码不会输出 1/-1 提示（`=> Goto 0` 在 `◢` 之前跳转），与原页说明文字不符，属原始数据问题。
- 字节数按「每 token 1 字节 + 数字每位 1 字节」计算，16 条中 11 条与标称值一致；不一致的多为原页对多位数计法不同。
